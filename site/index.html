Three ways to get a map

Every way in produces the same plain model: which parts exist and what connects them, with no coordinates. The layout is Cartographer's job.

A

Point it at a code folder

Cartographer reads the project on your disk, never uploading it. It understands docker-compose services, npm, yarn and pnpm monorepos, Node, Python, Go and Rust manifests, and the real import graph of JavaScript, TypeScript and Python code. View 1 above came from this file:

B

Describe it in plain English

Write a few sentences and AI drafts the map. By default the model runs on your computer with Ollama, so nothing you write leaves it. You can opt in to the Anthropic API with your own key.

C

Paste Mermaid, or draw it yourself

Paste a flowchart, sequence or state diagram. Cartographer keeps the meaning and draws it fresh. Or start blank and add boxes by hand.

The machine arranges. You decide.

Most diagram tools make you choose: neat automatic layout you can't touch, or a whiteboard you tidy by hand forever. Cartographer does both. It arranges everything, and when you move a box it stays put. Press Auto-layout and the rest of the map flows around the boxes you placed.

Group boxes into labelled boundaries, select two to trace the route between them, or click one to light up everything it reaches.

When the code changes, the map shows you what moved.

Hand-drawn diagrams go stale the week they're made. Re-scan the folder and Cartographer marks every revision before anything changes: what was added, what's gone, what's different. Accept it, and your pins, the boxes you added yourself and your edits all stay.

General notes

  1. Five kinds of diagram. System overviews, step-by-step processes, conversations between parts over time, data flows, and the states something moves through.
  2. Editable all the way. Rename in place, connect by dragging, change several boxes at once, undo anything.
  3. Exports. SVG and PNG images, a 1200×630 card for a README or a post, Mermaid text, and .crtgrphr files that diff cleanly in a pull request.
  4. Private by default. Scanning is local. The AI runs locally unless you switch it to the Anthropic API with your own key, which is encrypted with your system keychain.
  5. Free and open source under the MIT licence. Built by one developer.
